# LunchVoice fonts for Canva and other tools

| Font | Use | Weight | In Canva | If missing |
| --- | --- | --- | --- | --- |
| Bricolage Grotesque | Headlines, the tagline, big numbers | ExtraBold (800) | Yes | Archivo ExtraBold, then Arial Black |
| Geist | Sentences, buttons, captions | Regular, Medium, SemiBold | Yes | Inter, then Arial |
| Space Mono | Web addresses, codes, numbers | Regular, Bold | Yes | IBM Plex Mono, then Courier New |

All three are free under the SIL Open Font License and can be downloaded from Google Fonts for video editors and
desktop apps. Font files are not stored in this kit.

Headline settings: letter spacing about -45 in Canva (-0.045em), line spacing about 0.95, sentence case.
Web address: lower case, `lunchvoice.com`.

Sizes for every use are in `../documentation/TYPOGRAPHY.md`.
