# The Lunch Line — agent onboarding

**Read this first.** A full knowledge-graph map of this project exists at
`graphify-out/wiki/index.md` — 190 nodes across 15 communities (auth shell,
menu data, admin, edge functions, design system, deps). Start there for
architecture context, then drill into a community or god-node article before
touching code.

- **Map / where things live:** `graphify-out/wiki/index.md` (crawlable, one
  article per community + per god node)
- **Ask the graph a question:** `graphify query "<question>"`
- **Audit report:** `graphify-out/GRAPH_REPORT.md`
- **Raw graph data:** `graphify-out/graph.json`

Rebuild after significant changes: `/graphify --update`.
